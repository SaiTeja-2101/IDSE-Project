# Assignment rubric

The rubric asks for a game where a beginner discovers a data science concept through play.

| Criterion | Marks available | Where to verify it |
| --- | ---: | --- |
| Concept coverage and correctness | 1.5 | Make and label a decision, follow both learned tree paths, and separate the training labels from the work test results. The lesson also shows bias, proxies, false positives, false negatives and held-out evaluation. See [learning goals and data](GAME_DESIGN.md). |
| Game design and learning loop | 1.5 | Play the three rounds, choose an archive, reply to a named CV case, change one detail and try a repair. These decisions supply training labels, choose training inputs or change what is evaluated. Their effects appear in feedback based on the current run. |
| Implementation | 1 | Run the game from the static build. Scout fits and refits real CART trees on synthetic data; the paths, complaint and tables are computed. See the [verification record](DELIVERY.md). |
| Documentation and evidence of learning | 1 | [How to play](../README.md) and the [game design](GAME_DESIGN.md) are ready. The [playtest guide](PLAYTEST.md) records actual observations; real beginner sessions and a revision based on them are pending. |
| Total | 5 | |

For a live demo, show the inbox case, the original and copied CV paths, and the two models' final results. Use your run's numbers. A tie or a worse result is a valid finding: explain it from the table.

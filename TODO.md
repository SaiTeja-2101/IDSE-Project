# Hire & Seek: delivery checklist

See [the detailed game design](docs/GAME_DESIGN.md) for rules, learning objectives and the implementation decisions for each phase.

- [x] Phase 1: Animated office, click to open CVs, three rounds, timer, fixed shortlist targets.
- [x] Phase 2: Engineer handoff, choose an archive, fit Scout to real training examples in the game.
- [x] Phase 3: Scanner, investor update, computed complaint or routine case, inspector and city report.
- [x] Phase 4: Test one detail on the actual case and compare learned paths.
- [x] Phase 5: Try independent repairs on 80 practice CVs. Lock one for evaluation on 200 new CVs.
- [x] Phase 6: Interactive recap, local save and resume, downloadable audit receipt.
- [x] Phase 7: Local build, automated checks, assignment documentation and packaging script.
- [ ] Check rendered layout in Chrome at desktop and phone widths, keyboard and touch controls, and audible cues including mute/pause.
- [x] Record five peer comments and improve the inspector, repair explanations, and final results using their feedback.
- [ ] Ask a peer to try the revised screens and record what changed for them.

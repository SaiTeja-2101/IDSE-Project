# Hire and Seek logo

The game keeps its VT323 typeface, cream paper, navy ink, teal controls, and amber accents. The new symbol shows Scout peeking out of an applicant folder. It connects hiring with the idea of looking closer.

The logo is `game-source/public/game/assets/img/hire-and-seek-logo.png`. It was generated using the built-in imagegen tool, with a transparent background, on 2026-10-30. The selected output was copied into the project. It is used next to live text, so the game name stays sharp and readable. The separate Orbit Works mark remains the fictional company's symbol in messages.

## Generation prompt

Use case: logo-brand. Create one finished brand symbol for the playful educational browser game Hire & Seek. Symbol only, NO TEXT, no wordmark. A clever chunky pixel-inspired manila applicant file folder, with a small dark navy computer face peeking over its top edge: two mint rectangular eyes, Scout the learning assistant. The folded page/file corner subtly resembles a search tab. Distinctive silhouette, geometric and crisp, hand-designed indie game identity with a premium editorial sensibility. Palette: midnight navy #142d4e, warm amber #f0b84b, teal #2bb3a3, cream #f6f1e8. Flat solid fills, restrained hard offset shadow, angular corners with small stepped pixel details. Centered icon, fills the canvas with moderate margin, actual transparent background. Legible at 40px. Avoid generic AI sparkles, brains, gradients, gloss, 3D, tiny decoration, magnifying-glass cliches, extra icons, mockups and any text.
